ب) برای این که هرکتاب میتواند چند نویسنده و هر نویسنده میتواند چند کتاب داشته باشد و از ذخیره سازی نامناسب و تکراری جلوگیری میکند

ج)
 CREATE TABLE Categories (
    category_id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL
)

CREATE TABLE Books (
    book_id SERIAL PRIMARY KEY,
    title VARCHAR(200) NOT NULL,
    category_id INT,
    FOREIGN KEY (category_id)
        REFERENCES Categories(category_id)
)

د) زیرا هر کتاب میتواند چند نسخه فیزیکی داشته باشد .
 جدول کتاب اطلاعات کلی و عمومی مثل عنوان و نویسنده را میگیرد .
 ولی جدول کپی اطلاعات هر نسخه کتاب مانند شناسه و وضعیت امانت را ذخیره میکند
 این جداسازی از تکراری بودن اطلاعات جلوگیری میکند 
 و امکان مدیریت هر نسخه فیزیکی کتاب را فراهم میکند
